# Cut-Through VOQ Switch

4-port input-queued network switch with Virtual Output Queue (VOQ) architecture,
strict-priority QoS arbitration, and cycle-accurate latency bounds.
Architecturally inspired by the packet classification and routing subsystem
of the Nvidia BlueField SmartNIC DPU.
